갱신: 2026-10-18 (Asia/Seoul)

## 현재 위치

**요구분석명세서 v0.3/R1 작성 완료·검토본, 기능·상호작용 설계 D0.1 초안.** 기존 기능 요구 24개·비기능 요구 6개의 상세 내용과 유스케이스·설계·검증 추적표를 정리했다. 사용자 결정·개발 제안·미정 정책을 구분하며 요구 기준선·첫 배포 범위는 미확정이다. 새 기능은 추가하지 않았고 세부 아키텍처·클래스·실기 시험·앱 구현은 미수행이다. COCOMO는 학습용이며 실무 일정은 미정이다.

2026-10-18에는 요청에 따라 요구분석을 보완하여 [유스케이스 목록 UC0.1](USE_CASES.md)을 작성했다. 목적 중심 18개·외부 연동 2개를 식별하고 액터·결과·요구 연결·상태와 빠른 확인 상세화 예시를 기록했다. 기존 전체 여정 2개는 중복 집계하지 않는다. 기능·수용 기준 변경이 없어 명세 v0.3·설계 D0.1을 유지한다.
이어 사용자 지정 일곱 항목으로 [유스케이스 명세서 UCS0.1](USE_CASE_SPECIFICATION.md)의 사례 20개·전체 여정 2개를 작성했다. 우선순위는 검토 순서의 제안이며, 미정 정책·비기능 수치는 확정하지 않았다. 앱 구현·실기 검증은 아직 미수행이다.

## 제안된 첫 구현 흐름 — 미확정

가상 외부 사건 수신 → 중복 없는 저장 → 자동으로 알 수 없는 내용만 알림·짧은 UI로 확인 → 분석·계획 변경 후보 검토. 실제 기기 연동 시험과 단계적으로 연결하는 방안을 검토한다.

기존 '예시 주간 계획 표시 → 수정·승인 → 저장'은 후속 하위 흐름으로 유지할 수 있다. 최초 사용 흐름으로 바로 시작하지 않는다.
기존 COCOMO 산정 범위에는 이번 초기 관찰·분석 요구가 명시적으로 반영되지 않았다. 이전 공수·네트워크·간트는 새 범위의 일정으로 재사용하지 않는다.
지속 수집·외부 연동·백그라운드·잠금 상태·능동 알림도 새로운 범위이며 추가 분석과 검증이 필요하다.
PC 동기화는 이번 산정에서 제외한다. v0.1 범위는 아직 사용자 확정 전이다.
