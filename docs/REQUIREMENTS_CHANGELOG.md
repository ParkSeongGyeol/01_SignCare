# 요구분석명세서 변경 이력

작성: 2026-10-17 / 갱신: 2026-10-18 (Asia/Seoul)
현재 명세 기능 버전: v0.3 / 문서 개정: R1 / 현재 설계 참조: D0.1

## 관리 규칙 — 사용자 요청 반영

- 기능 추가·삭제 또는 관찰 가능한 동작·수용 기준 변경 시 명세 버전을 v0.4, v0.5 등으로 올린다.
- 변경 날짜, 이유·요청 근거, 영향받는 요구 ID와 설계·테스트를 기록한다. 수정된 요구의 최초 도입 버전은 유지한다.
- 문장·링크 정리나 기존 요구를 실현할 설계 작성만으로 기능 버전을 올리지는 않는다.
- 설계 문서는 D0.1 등 별도 버전과 참조 명세 버전을 기록한다. 새 기능이 필요해지면 명세 변경부터 함께 반영한다.
- 초안·사용자 의도 확인·상세 합의·구현 완료·검증 완료를 구분한다. 버전이 올라갔다고 모두 합의·구현된 것은 아니다.
- 폐기한 요구 ID는 재사용하지 않고 사유를 남긴다.
- 정확한 과거 시각은 남아 있지 않으므로 기존 버전의 날짜만 기록한다. 아래 '도입'은 아이디어의 최초 발언일이 아니라 명세서에 해당 ID가 들어간 버전이다.
- 아래 이력은 기존 대화와 저장된 초안을 근거로 정리한 요약이다. 과거 파일 전체를 새로 복제하거나 과거 커밋이 존재한다고 주장하지 않는다.
