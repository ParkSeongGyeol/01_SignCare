# 개인 건강관리 튜터 앱

이 저장소는 개인이 직접 사용하며 개선할 건강관리 튜터 앱의 설계와 개발 기록을 보관한다.
작성 기준일: 2026-10-15 (Asia/Seoul).

## 저장소

[ParkSeongGyeol/01_SignCare](https://github.com/ParkSeongGyeol/01_SignCare)의 `main`에서 이 프로젝트를 관리한다.
기존 프로젝트 파일은 현재 문서로 교체하며, 이전 커밋 이력은 유지한다.
현재 작업 폴더의 Git 원격 `origin`은 위 저장소를 가리킨다.
연결만으로 자동 업로드되지는 않으며, 개발 변경은 검토 후 커밋하고 푸시한다.
공개 저장소이므로 개인 건강·생활 정보와 비밀키는 업로드하지 않는다.

2026-10-17 요구분석명세서 v0.3은 **지속 자동 수집·짧은 알림 응답 → 3·7·15일 단위 루틴 분석 → 선택한 관리 방향에 맞는 변경 제안 → 승인·실행·매일 조정**을 반영한다. 증량·유지·감량을 선택하며 초기 관찰 이후에도 수집이 계속된다. 정밀 신체 변화 측정은 후속 검토다. 연동 경로·분석 창·자동 변경 권한·상세 요구와 첫 배포 범위는 아직 합의 전이다.

현재는 설계 단계로 넘어가 D0.1을 작성했다. 새 기능이나 요구 동작이 바뀌면 명세 버전·변경일·영향 ID를 기록한다. D0.1은 기존 요구를 구체화한 초안이므로 명세 버전은 v0.3을 유지한다.
2026-10-18에는 요구분석을 보완하여 유스케이스 목록 UC0.1을 작성했다. 기존 전체 여정과 목적 단위의 사례를 구분하고 사용자 방향·개발 제안·미정 사항을 표시했다. 기능 변경은 없으며 상세 합의·구현은 아직 수행하지 않았다.
같은 날 요청한 일곱 항목으로 유스케이스 명세서 UCS0.1을 작성했다. 우선순위는 검토 순서의 제안이며, 미정 정책·품질 수치를 확정하지 않았다. 기존 요구의 상세 초안으로 명세 v0.3·설계 D0.1을 유지한다.
이후 요구분석명세서를 v0.3/R1 작성 완료·검토본으로 정리했다. 기존 30개 요구의 상세 동작·검증 방법, 데이터·연동·공통 업무 규칙, 전체 추적표와 미정 정책을 포함한다. 기능 의미를 바꾸지 않아 기능 버전은 유지하고 문서 개정 R1을 표시했다. 사용자 요청에 따라 지금까지의 계획·분석·설계 산출물을 원격 저장소에 함께 반영한다.

2026-10-16 계획 초안은 COCOMO II Early Design과 주 20시간을 기준으로 작성했다.
소프트웨어 공학 기법을 실제로 연습하는 것이 개발 목적에 포함된다. 비용·일정은 아직 보정하지 않은 교육용 추정이며 확정 납기가 아니다.
연구 검토 후 기존 105.85주를 실무 일정으로 채택하지 않기로 정리했다. AI 보조 작업의 실제 공수를 측정하여 별도 계획을 만드는 것은 다음 제안이며 아직 수행하지 않았다.

현재 확정된 앱 프레임워크는 **Flutter**, 언어는 Dart다. Android를 우선 대상으로 한다.
아직 앱 코드, SDK 설치, 빌드, AI 연결, 데이터 저장 및 동기화 구현은 시작하지 않았다.
폴더 이름인 SignCare는 앱의 공식 명칭으로 확정된 것이 아니다.

이 문서는 대화의 의미를 보존한 요약이며 원문 녹취록은 아니다.
